01 / fundamentos

O rádio precisa concordar em quatro coisas.

Para uma comunicação simples entre rádios, a configuração deve ser compatível. Comece pelo essencial e deixe os menus avançados para depois.

Onde falar

Frequência

É o número do canal de rádio, por exemplo 463.525 MHz. Dois rádios precisam estar na mesma frequência para comunicação simplex.

Como falar

PTT

Push To Talk. Pressione para transmitir e solte para voltar a receber. Evite falar antes de pressionar o PTT.

O que abre o áudio

CTCSS / DCS

São códigos de squelch. Quando usados, o receptor pode exigir o código correto antes de abrir o áudio.

Modelo de operação

Simplex

Os rádios se comunicam diretamente. Em uma configuração simplex, RX e TX usam normalmente a mesma frequência. É o modelo mais simples para jogos.

Controle de ruído

Squelch

Define quanto sinal é necessário para abrir o áudio. Squelch não é volume e não melhora o alcance.

02 / códigos

CTCSS e DCS não mudam a frequência.

Eles funcionam como uma segunda condição para o squelch. O rádio continua transmitindo na frequência configurada.

Subtom analógico

CTCSS

Usa um tom baixo, como 69.3 Hz. Um rádio pode transmitir esse tom e o outro pode exigir o mesmo tom para abrir o áudio.

Código digital de squelch

DCS

Usa uma sequência/código, como D331N. A letra N indica a forma normal do código em muitos equipamentos.

Regra prática: se um canal do BF-777S possui CTCSS ou DCS, o UV-5R precisa receber a mesma informação para reproduzir a comunicação de forma compatível. Para DCS, use o mesmo código em transmissão e recepção quando a configuração do canal for simétrica.
DCS/CTCSS não são criptografia. Eles não escondem a conversa. Um terceiro pode monitorar a frequência de outras formas e, se descobrir a configuração, pode reproduzir o mesmo código.

06 / squad

Um canal compartilhado pelo grupo.

Quando todos os integrantes usam UV-5R, é possível criar uma configuração comum e salvá-la como um canal. A frequência deve ser uma frequência autorizada para o equipamento e para o evento.

Por que usar um código?

Menos ruído, não invisibilidade.

Se outros grupos usam a mesma frequência com códigos diferentes, o CTCSS/DCS pode impedir que o áudio deles abra o alto-falante. Isso ajuda a separar conversas.

O mesmo recurso não impede que outro rádio monitore a frequência nem protege o conteúdo da conversa.

Não crie uma “frequência secreta” fora da faixa autorizada. Uma frequência só deve ser usada quando for permitida. O objetivo de um canal de squad é organizar a comunicação e reduzir interferência, não burlar regras de rádio.
07 / interferência

“Canal privado” tem um significado limitado.

Em UV-5R e BF-777S analógicos, CTCSS/DCS são recursos de filtragem. Eles não fornecem confidencialidade.

Ajuda

Menos abertura de áudio

O rádio pode ignorar transmissões que não tenham o CTCSS/DCS esperado.

Ajuda

Menos configuração acidental

Um jogador que apenas seleciona a mesma frequência, mas não conhece o código, pode não ouvir o áudio no modo de squelch codificado.

Não ajuda

Contra monitoramento

Um terceiro pode descobrir a frequência e identificar o código. A transmissão analógica não fica criptografada.

Boa prática para jogos: combine previamente um canal principal e um reserva, mantenha a configuração dentro das regras do evento e evite divulgar a tabela de canais além do necessário.

03

CÓDIGO

04

PTT

Faça uma chamada curta e solte o botão para ouvir.

RESERVA

Teste o canal alternativo antes do jogo.

Alcance não é um número fixo. Distância, prédios, mata, relevo, altura da antena, orientação do rádio, potência e interferência mudam o resultado. Números de “X km” de anúncios ou vídeos não devem ser tratados como garantia.
09 / sem código

Todos ouvem todos: a configuração básica.

Se todos os UV-5R estiverem na mesma frequência com CTCSS/DCS desligados, conseguem se comunicar normalmente — desde que estejam no mesmo modo e em operação simplex.

EXEMPLO · CANAL ABERTO (SEM CÓDIGO)
FREQUÊNCIA     444.250
MODO           FM / WIDE
OFFSET         000.000
SHIFT          OFF

R-CTCSS        OFF
T-CTCSS        OFF
R-DCS          OFF
T-DCS          OFF

Quando configurado assim, todos os UV-5R na frequência conseguem ouvir e falar. Não há filtro de código.

Vantagem

Simplicidade

Não exige sincronização de um código adicional. Qualquer pessoa com UV-5R sintonizado naquela frequência participa.

Limitação

Sem filtragem

Se outro grupo usar a mesma frequência, ambos irão interferir. Não há separação.

Importante: configurar a frequência corretamente não significa que ela seja sua "frequência privada". Qualquer rádio sintonizado nela pode ouvir. Se a frequência estiver autorizada para o evento e não ocupada naquele momento, funciona bem para um squad interno.
10 / qual código

CTCSS ou DCS: qual usar?

Para um squad que utiliza somente UV-5R, DCS é a escolha mais prática. Os dois fazem essencialmente a mesma coisa, mas com técnicas diferentes.

Ton analógico

CTCSS

Usa um tom de áudio muito baixo contínuo, por exemplo 69.3 Hz. O transmissor envia esse tom junto com a comunicação.

Código digital

DCS

Usa um código digital, por exemplo D331N. A letra N indica o modo normal do código.

Para o squad

RECOMENDADO · SQUAD COM DCS
FREQUÊNCIA     444.250
DCS TX         D331N
DCS RX         D331N
CTCSS TX       OFF
CTCSS RX       OFF
OFFSET         000.000
SHIFT          OFF

Todos os UV-5R precisam ter exatamente a mesma configuração. O código funciona como um filtro de squelch adicional.

Por que DCS para o squad? É mais prático porque o código já está integrado nas memórias do UV-5R. Ambos (CTCSS e DCS) fazem a mesma coisa no final: permitem que o rádio receptor decida se deve abrir o áudio. Para operação em equipe com múltiplos UV-5R, DCS oferece uma configuração mais direta.

O filtro de código

Um rádio em 444.250 + D331N conversa normalmente com outro em 444.250 + D331N. Mas um rádio em 444.250 + D023N pode ficar silencioso, porque o código recebido não corresponde.

Resultado

Separação operacional

Se outro grupo usar a mesma frequência com um código diferente, o áudio de um não abre o alto-falante do outro.

Resultado

Menos interferência

Reduz ruído de outras transmissões na mesma frequência, melhorando a clareza.

Resultado

Fácil sincronização

Todos recebem e transmitem o código automaticamente; não exige coordenação extra.

Isso não é criptografia ou sigilo. CTCSS/DCS não escondem a conversa. Um terceiro pode monitorar a frequência, descobrir o código e participar. O rádio do UV-5R não oferece recursos de criptografia; o código serve apenas para controlar qual transmissão o squelch deixa passar. Pense nele como um filtro, não como uma senha.

Resumo da escolha

✓

✓

✓

✓

✓
